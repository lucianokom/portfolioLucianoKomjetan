Proyectos

Proyecto Académico en Java

Desarrollo de una aplicación dentro del ecosistema Java / Java EE basada en una arquitectura cliente-servidor. El sistema cuenta con un servidor central desarrollado en Java con interfaz gráfica en Java Swing, destinado a la gestión y administración del sistema por parte del administrador. Paralelamente, se implementó un servidor web utilizando tecnologías JSP y Servlets, encargado de servir la aplicación web accesible para los usuarios a través del navegador. La aplicación fue diseñada siguiendo el patrón arquitectónico MVC para garantizar la separación entre la lógica de negocio, la capa de presentación y el control de la aplicación. El proyecto fue estructurado y gestionado mediante Apache Maven para la gestión de dependencias y el proceso de construcción.

Proyecto Académico en C++

Desarrollo de una aplicación en C++ ejecutada en entorno de consola, implementando una interfaz de interacción basada en menús para la gestión de operaciones del sistema. El proyecto fue desarrollado aplicando el paradigma de Programación Orientada a Objetos (POO), utilizando conceptos como encapsulamiento, abstracción y organización modular del código mediante clases y métodos. La aplicación gestiona la lógica del programa a través de estructuras de control y manejo de datos en memoria, permitiendo una interacción clara y estructurada con el usuario desde la interfaz de consola.

Portafolio web
